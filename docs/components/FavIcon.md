One-line: the square dale mark — app icon, favicon, avatar-scale brand signature where the full lockup will not fit.

```jsx
<FavIcon size={64} />
<FavIcon size={64} background="var(--dale-black-pure)" markColor="var(--dale-yellow)" ring="dark" />
<FavIcon size={64} background="var(--dale-white)" ring="light" />
```

Notable:
- Only the three combinations above appear in the Brand frame; do not invent new ground/mark pairs.
- The chevrons keep their offset ratio at every size — pass `size`, never scale with CSS transforms.
